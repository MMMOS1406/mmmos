PER-QUESTION GRADING
Q1 Private server integration ........... ANSWERED-NO (for MCP)
   Suno: MCP is for supported AI assistants (Claude, ChatGPT, Claude Code, Gemini, Cursor).
   It is not a server-to-server API. A private backend such as MMMOS cannot call it as its
   backend interface. Backend orchestration requires Suno Public API access.
Q2 Exact lyrics and style; status ....... CONDITIONAL
   MCP supports complete custom lyrics and custom style prompts (like Custom mode), but only
   inside a supported AI assistant. Backend status polling is not an MCP purpose; it points
   to the Public API.
Q3 MP3 retrieval ......................... ANSWERED-NO (for MCP)
   Songs land in the Suno Library. Background MP3 retrieval is not an MCP purpose; it points
   to the Public API.
Q4 Commercial downloads .................. ANSWERED-YES (with the Pro limit)
   Pro songs carry commercial-use rights and may be monetized on YouTube and elsewhere; Suno
   takes no share. Pro download limits apply regardless of MCP (20 per month).
   Per-song vs per-version counting and re-downloads: not answered.
Q5 Shared Pro account .................... ANSWERED-YES
   One Pro account may serve multiple owned channels and projects (SRV Studio and SRV Farsi).
Q6 Costs and scopes ...................... PARTIAL
   MCP has no separate charge and uses plan credits. The Public API is negotiated separately
   and is not included in Pro.
   Not answered: credits per generation, rate limits, extra-download price, narrower OAuth
   scopes.
Q7 Availability .......................... ANSWERED-YES (with limitation)
   MCP is beta / early access; a waitlist is required. This account's waitlist status is
   unknown.

WHAT MCP CAN AND CANNOT DO FOR MMMOS
Can:
- A human using a supported AI assistant (for example Claude) can have Suno generate a song
  from exact lyrics and style. The song lands in the Suno Library.
- That song has full Pro commercial rights. There is no extra charge.
Cannot:
- MMMOS cannot call MCP from its server.
- MMMOS cannot poll generation status or fetch the MP3 automatically.
- The VA would still download from Suno and drop the file into MMMOS.
- So MCP saves at most the copy-paste step, and it adds an assistant-account dependency plus
  a beta waitlist.
Assessment: MCP is NOT recommended for SRV Studio production.
