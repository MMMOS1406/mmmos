STEPS

   Keep the returned run_id as agent_run_id for every call below.

   eb_worker_read_adviser_followups. The boundary and scope limit what you may do.

     cd ~/mmmos-runner/repo && git fetch origin && git status --porcelain

     git checkout -b runner/<id8>-<ts> origin/main

6. Do the task, inside the allowed folders only. Call eb_worker_renew_lease at least every 20 minutes.
   Run the tests that cover what you changed.

11. Call eb_worker_submit_evidence (evidence_type test_result) with a one-paragraph summary and the PR link.
12. Stop. Report: task id, PR link, artifacts uploaded, anything that failed.

ON ANY ERROR: call eb_worker_submit_evidence (evidence_type note) describing the failure if you hold a claim,
leave the branch in place for review, and stop. Never retry a failed push, PR, upload or claim in a loop.
