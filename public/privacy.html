MMM OS

Privacy Policy

Effective date: May 26, 2026  ·  Last updated: May 26, 2026

MMM OS ("we", "our", or "us") is a private dashboard application used to manage content operations, financial tracking, and platform integrations. This Privacy Policy explains what information we collect, how we use it, and how we protect it.

1. Information We Collect

We collect only the information necessary to operate the dashboard:

  • YouTube data: Channel statistics, video metadata, view counts, and subscriber counts — fetched via the YouTube Data API v3 with read-only OAuth access.
  • TikTok data: Account display name, follower count, video metadata — fetched via the TikTok API with read-only OAuth access.
  • Financial data: Manually entered income, expense, debt, and portfolio figures stored locally and in our database.
  • OAuth tokens: Access and refresh tokens for connected platforms, stored securely in our Supabase database to enable periodic syncing.
  • Usage data: Basic server logs generated by Vercel (request timestamps, status codes). No personal analytics or tracking pixels are used.

2. How We Use Your Information

All collected data is used exclusively to power MMM OS features:

  • Displaying channel performance metrics and content analytics
  • Syncing platform data on demand or via scheduled cron jobs
  • Calculating financial health scores, debt payoff projections, and net worth
  • Generating weekly performance reports stored in our database

We do not sell, rent, or share your data with any third party for marketing or advertising purposes.

3. Data Storage

Data is stored in a Supabase (PostgreSQL) database hosted on secure cloud infrastructure. OAuth tokens are stored with expiration timestamps and are refreshed automatically. Financial data entered manually is also persisted to localStorage in your browser as a local backup.

4. Third-Party Services

MMM OS connects to the following external services:

  • YouTube Data API v3 (Google LLC) — read-only channel and video data
  • TikTok API (ByteDance Ltd.) — read-only account and video data
  • Supabase — database and authentication infrastructure
  • Vercel — hosting and serverless function execution
  • Anthropic Claude API — content package generation

Each of these services has its own privacy policy governing how they handle data. We encourage you to review them.

5. Data Retention

Sync logs and completed job records are purged after 30 days. Channel and video data is retained indefinitely to support historical trend analysis. You may request deletion of all stored data at any time by contacting us.

6. Security

Access to the MMM OS dashboard is protected by a PIN-based authentication system. All API communication uses HTTPS. OAuth tokens are never exposed to the client beyond what is necessary to initiate sync operations. We apply the principle of least privilege — all platform OAuth scopes are read-only where the platform permits.

7. Your Rights

You have the right to:

  • Request a copy of all data stored about you
  • Request correction of inaccurate data
  • Request deletion of all stored data
  • Disconnect any connected platform at any time via the Integrations tab

8. Changes to This Policy

We may update this Privacy Policy from time to time. The effective date at the top of this page will reflect the most recent revision. Continued use of MMM OS after changes constitutes acceptance of the updated policy.
